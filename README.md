# Frontend Website Desa Pringgodani (Lokal Pringgodani)

Frontend aplikasi web resmi Desa Pringgodani berbasis Next.js App Router, Tailwind CSS, dan TypeScript.

## Fitur & Dokumentasi
- Panduan arsitektur dan teknis lengkap frontend tersedia di folder [`docs/`](./docs/).
- Spesifikasi pengujian perangkat lunak dan matriks ketertelusuran (TDS & TTM) tersedia di [`TDS_TTM_Lokal_Pringgodani.md`](./TDS_TTM_Lokal_Pringgodani.md).
